# Batch 11 contract: OPF and EPUB metadata boundary

Targets: `server/utils/parsers/parseOpfMetadata.js` and `parseEpubMetadata.js`. Parser Sub-Agent owns only these two files in its isolated worktree. This contract is frozen before implementation.

- `parseOpfMetadata` exports named `parseOpfMetadataJson` (synchronous arrow) and `parseOpfMetadataXML` (async arrow). The latter calls `this.parseOpfMetadataJson`; keep that receiver-sensitive call. `parseOpfMetadataJson` finds prefixed or unprefixed package/metadata nodes, overwrites `metadata.meta` on the passed JSON object, resolves creator roles and refinements, deduplicates names/genres/tags/series, sanitizes description and returns the same nullable metadata fields. Keep odd/malformed-input behavior, including existing errors.
- `parseEpubMetadata` exports named `extractCoverImage` and `parse` functions. Preserve `StreamZip.async` construction, `entryData`/`extract`/`close` ordering, resolved failures and logged errors. `parse` reads `META-INF/container.xml`, then package OPF, passes a `structuredClone` to the OPF parser, and selects cover by explicit ID, `cover-image` property, then first image. Keep path joining, payload key presence, warnings and existing fallbacks. Do not turn archive failures into new returns.
- Preserve direct CommonJS exports, callable names/constructibility, require order and public path. Existing tests cover some OPF series inputs; add offline fixed baseline/candidate samples for mutation, namespace, title/creator, malformed XML, EPUB archive success and failure. Real EPUB files may remain untested but must be recorded.
- No test, scanner, `parseEbookMetadata`, archive library, utility index, config, lockfile or shared-type edits. Preserve strict build and all 356 original tests. Report contract conflicts to the main Agent; commit only the two source renames and report SHA, checks, elapsed time and visible/requested model.
