★ Insight ─────────────────────────────────────
- utils/index.js has arrow functions at module scope that call this.isObject(…). In CommonJS, top-level this is module.exports, and arrow functions capture it. Today that works because module.exports.isObject = … populates that same object.
- Convert the file to a trailing export = { … } and TypeScript emits module.exports = { … } — a new object. The arrows still hold the old one, which no longer has isObject on it. The code compiles, the require shape looks identical, and it throws at runtime.
- So the 40-importer hub file genuinely cannot take the export = form without a code change. That is a property of the file, not a time problem, and CLAUDE.md doesn't anticipate it.
