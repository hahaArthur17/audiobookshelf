RESULT: 0 occurrences of `any` in the declaration output. There is no file, line or source to list.

NOTE: the any count is a LOWER BOUND.
Declaration output covers only the declared and exported types: class fields, method signatures, and the module-local
interfaces and type aliases they reference. It does not show:
- `any` inside function bodies (local values that are never part of a signature);
- `any` inside types imported from JS modules (e.g. the provider classes used as field types). Those belong to the JS
  modules, not to the finders.
