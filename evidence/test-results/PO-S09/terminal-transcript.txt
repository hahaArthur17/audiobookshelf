★ Insight ─────────────────────────────────────
- The line between "committed" and "restored" follows a JavaScript fact. Reading a property of false is legal and gives undefined, so it can be typed truthfully (X | (false & { ino?: undefined })). Reading a property of null throws, so only an assertion that the code does not back up will compile.
- A declaration file with global types looks harmless under a no-emit check. The incremental builder treats it as affecting the global scope and recomputes every file, which is what triggered the crash. A module .d.ts with import type costs the same and has no such effect.
