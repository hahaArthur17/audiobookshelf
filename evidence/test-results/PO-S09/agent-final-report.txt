Did CLAUDE.md work as written?

The controller recipes, the model pattern, the declarations section and the crash pitfall all worked. Gaps:

1. The probe: a bare rename cannot show missing declarations, and checkJs under-reports (untyped req.body).
2. No form for the inherited statics of the JavaScript LibraryItem model (TS2684; a cast to ModelStatic is refused with TS2352).
3. "Never use declare global" should also cover a declaration file with global declarations.
4. The ! rule has no case for a dereference the original leaves unguarded, and its three cases are worded narrowly.
5. Allowance 3 names a call and a parameter. It does not cover an assignment, a too-vague return type, or Sequelize's own typings (nested single include, where: null).
6. Allowance 2 names .message only.
7. For a JS function with a = null default, only a cast of the callee compiles; annotating the destructured import fails.
8. The grep filter hides errors a conversion causes elsewhere: PublicRouter.ts binds SessionController.getTrack, and this there is a PublicRouter.
9. The code has no semicolons, so a cast at the start of a line can continue the previous statement.
10. "Query values are strings" is wrong where a middleware rewrites them (limit, page in Library).
11. JSDoc typedefs that JS files import from a controller silently become any once it is TypeScript (PlaybackSessionManager.js 48, 76).
12. Per-controller commits cannot each be gated without stash or reset; I gated the whole tree.
13. Nothing says evidence/ is off limits; sparse checkout hides it from the tree but not from git show.

★ Insight ─────────────────────────────────────
- The line between "committed" and "restored" follows a JavaScript fact. Reading a property of false is legal and gives undefined, so it can be typed truthfully (X | (false & { ino?: undefined })). Reading a property of null throws, so only an assertion that the code does not back up will compile.
- A declaration file with global types looks harmless under a no-emit check. The incremental builder treats it as affecting the global scope and recomputes every file, which is what triggered the crash. A module .d.ts with import type costs the same and has no such effect.
